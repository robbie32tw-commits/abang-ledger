雲端同步（GitHub Gist）
用你自己的 私密 Gist 當儲存空間，在手機與電腦之間同步。資料只在你的瀏覽器與你的 GitHub 帳號之間往返，不經過任何第三方。
權杖會存在這台裝置的瀏覽器裡，不會上傳。請到 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) 建立，權限只勾 gist 這一項就好。

同步是明確的推 / 拉，不會自動合併 —— 兩邊都改過的話，後推的會蓋掉先推的。動作前先按「查看雲端狀態」比對筆數與時間。
帳戶
勾「信用卡」的帳戶會在記帳頁顯示未繳金額。刷卡算消費日、繳款算資金搬移，兩邊都記不會重複計算。
關鍵字自動歸類規則
輸入店家名稱時，命中關鍵字就自動帶入分類。以空白或逗號分隔。
「重新歸類全部」只會覆寫尚未手動指定分類的紀錄。
關於
阿邦記帳2 是單一 HTML 檔的離線記帳工具，資料只存在這台裝置的瀏覽器裡（localStorage），不會上傳任何地方。

建議定期用「匯出備份」存一份 JSON 到 備份/ 資料夾。
