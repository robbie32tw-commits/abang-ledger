# 阿邦記帳2 🐕

記帳與支出分析。單一 HTML 檔，離線可用，資料只存在你自己的瀏覽器裡。

**網址**：https://robbie32tw-commits.github.io/abang-ledger/

手機用 Safari 開 → 分享 → 加入主畫面，就變成獨立 App。本機也可以直接打開 `index.html`。

> ⚠️ **資料是綁網址的。** 瀏覽器的 localStorage 依「來源」隔離，所以本機 `file://` 開的資料，跟網址 `https://` 開的資料是**兩個互不相通的空間**；iOS 加入主畫面後的獨立 App 也可能自成一個空間。
>
> 換裝置或換開啟方式時，一律走 **設定 → 匯出備份** → 在新環境 **設定 → 匯入資料**。

## ⚠️ 備份（請認真看）

資料只存在你這台裝置的瀏覽器裡，**不會上傳到任何地方**（GitHub 上只有程式碼，沒有你的帳）。這代表：

- 清除瀏覽器資料 → **記錄全部消失**
- 換手機、換電腦 → **不會自動跟著走**
- App 會在「記帳」頁跳備份提醒（超過 14 天沒匯出，或滿 10 筆卻從未備份過）

所以請養成習慣：定期 **設定 → 匯出備份**，把 JSON 存進 `備份/` 資料夾或 iCloud。

`備份/` 已經寫進 `.gitignore`，匯出的檔案**不會被推上公開的 GitHub**。

---

## 為什麼做這個

原本 泓金龜 的記帳資料裡，147 筆支出有 111 筆是「生活消費」，圓餅圖只會是一個大餅，答不出「錢花到哪去」。阿邦記帳2 解決三件事：

1. **輸入夠快** → 你才願意記細
2. **自動歸類** → 打「家樂福」自己跳日用雜貨，不用每次想分類
3. **排除資金搬移** → 提款、儲值、轉帳、卡費不算消費，數字才是真的

## 四個頁面

| 頁面 | 做什麼 |
|---|---|
| **記帳** | 金額 → 店家 → 分類（自動）→ 存。數字鍵盤在手機上直接可按。最上方是**現金錢包**，隨時看得到錢包剩多少 |
| **明細** | 依月份看流水帳，可篩分類、搜店家；點任一筆可編輯或刪除。分類下拉有 **⚠️ 待補分類**，一鍵列出所有只寫了支付工具的紀錄 |
| **分析** | 月度總覽、分類佔比、固定 vs 變動支出、近 6 個月趨勢 |
| **設定** | 匯入匯出、帳戶管理、關鍵字規則編輯 |

## 第一次使用

1. 開啟 https://robbie32tw-commits.github.io/abang-ledger/ （或本機的 `index.html`）
2. 到 **設定 → 匯入資料**，選你的 `收支記帳_備份_*.json`（泓金龜匯出的）
3. 會自動重新歸類 188 筆歷史資料，並把儲值 / 提款 / 轉帳 / 卡費標記為「不計入分析」
4. 完成後自動跳到 **分析** 頁

## 匯入支援的格式

| 檔案內容 | 行為 |
|---|---|
| `qq_transactions`（本 App 的備份） | **取代**全部資料，完整還原含帳戶與規則 |
| `hj_transactions`（泓金龜舊版記帳） | **取代**全部資料，並自動重新歸類 |
| `hj_income`（泓金龜新版，只有收入） | **加入**現有資料，不覆蓋。重複的 id 會略過 |

泓金龜改版後的備份（如 `泓金龜_備份_2026-08-05.json`）已經沒有 `hj_transactions`，只剩收入與投資損益。收入會匯入；**投資損益會略過** —— 那是已實現損益不是消費，386 筆倒進流水帳只會淹掉記帳。

## 三個重要觀念

### 「看不見的錢」
分析頁會有一張警示卡，列出**花掉了但沒有明細**的金額：

- **只寫了支付工具** — 記成「全支付」「街口」「Line Pay」，不知道買了什麼
- **儲值 / 信用卡還款** — 錢流到別的地方才花掉，這裡看不到明細

（**現金提款不在這裡** —— 現金由錢包功能追蹤，花掉的部分會變成有分類的消費，真正弄丟的由盤點差額補上。）

匯入舊資料後這個數字會很大，那是歷史資料的先天限制，不是 bug。**記帳時寫「買了什麼」而不是「用什麼付的」**，這個數字就會慢慢縮小。

### 支付工具攔截
輸入「全支付」「街口」這類支付工具時，App 會擋下來要求你補上分類 —— 這是刻意的，為了確保未來的資料一定分析得出來。

### 現金錢包 💵

記帳頁最上面那張卡，追蹤「錢包裡還有多少現金」。點一下展開。

**餘額怎麼算**：不存餘額數字，而是從流水帳即時算出來 ——

```
餘額 =  領現（現金提款）
      + 收到的現金（收入且帳戶選現金）
      + 盤點多出的調整
      − 現金消費（支出且帳戶選現金）
      − 存回銀行
```

所以只要記帳時**帳戶選「現金」**，錢包就會自動扣。刷卡或轉帳的消費不會影響錢包。

**領錢不算消費**。提款只是錢從銀行移到口袋，真正的消費是你之後拿那些現金買東西時記的那一筆。這樣才不會重複計算。

### 盤點（重要）

現金一定會漏記 —— 這就是盤點的用途。數一下錢包裡實際有多少，填進去，系統補一筆差額讓帳面等於實際：

| 情況 | 處理 |
|---|---|
| **第一次盤點**，實際比帳面少 | 記成「現金期初調整」，**不算消費**。因為匯入的舊提款紀錄本來就沒有對應的支出，不該算在這個月頭上 |
| **之後盤點**，實際比帳面少 | 補一筆現金支出、標記「未知用途」，**計入總消費**。錢確實花掉了，總額才會是對的 |
| 實際比帳面**多** | 補一筆「現金調整」，不算消費。表示有領錢或收現金忘了記 |
| 餘額變成**負的** | 卡片會跳警告，代表漏記了領現。盤點一次就修正 |

**建議**：匯入舊資料後先盤點一次建立期初，之後每週或每月盤一次。盤得越勤，「未知用途」的金額越小。

### 固定 vs 變動
房租、訂閱、保險會被標成「固定支出」。想省錢要從**變動支出**下手，固定支出得先改合約或搬家才動得了。沒被自動抓到的，可在明細點開手動勾選。

## 分類

**支出**：餐飲、日用雜貨、交通、居住、訂閱服務、醫療健康、美容治裝、娛樂學習、3C設備、網購、人情捐贈、繳費、其他

**收入**：薪資、兼職、獎金、投資收益、其他收入

**資金搬移**（不計入消費）：儲值、現金提款、帳戶轉帳、信用卡還款、借貸還款

分類規則可在 **設定 → 關鍵字自動歸類規則** 自行增減。改完可按「重新歸類全部」套用到舊資料 —— 只會動到沒有手動指定過分類的紀錄。

## 圖示

| 檔案 | 用途 |
|---|---|
| `icon.png` | 原始圖（1024px），要重做其他尺寸從這個檔轉 |
| `icon-512.png` | 大尺寸備用 |
| `icon-180.png` | 分頁 favicon + iOS「加入主畫面」圖示 |
| `icon-64.png` | 小尺寸備用 |

頂部標題列的小圖示是**內嵌在 HTML 裡**的（48px base64），所以就算只把 `index.html`單獨搬走，標題列還是有圖。分頁 favicon 和主畫面圖示則需要 `icon-180.png` 跟 HTML 放在同一個資料夾。

要換圖時：把新圖存成 `icon.png`，然後跑

```bash
cd ~/Documents/克勞德扣/阿邦記帳2 && for s in 512 180 64; do sips -Z $s icon.png --out icon-$s.png; done
```
